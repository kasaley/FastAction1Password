# 1Password для FastAction

[English](README.en.md)

Часто используемые записи 1Password в панели
[FastAction](https://github.com/kasaley/fastActionVersions): поля под рукой, копирование
в один клик и автозаполнение в активное приложение.

![Вкладка 1Password](https://github.com/kasaley/fastActionVersions/raw/main/docs/screenshots/tab-com.fastaction.onepassword.png)

## Что умеет

- **Список записей** из вашего сейфа — логины или всё подряд, можно ограничить одним сейфом.
- **Поля записи** в панели: логин, пароль, одноразовый код, ссылка. Копирование в один клик.
- **Буфер очищается сам** через заданное время — по умолчанию 45 секунд.
- **Автозаполнение**: логин и пароль вводятся в активное приложение по кнопке.
  Выключается в настройках плагина.

## Установка

Нужен официальный [1Password CLI](https://developer.1password.com/docs/cli/) (`op`)
и включённая в нём интеграция с приложением 1Password — именно оно спрашивает у вас
разрешение на доступ, а не плагин.

**Настройки → Плагины** в FastAction: плагин есть в каталоге. Вручную — скачайте архив
из [релизов](../../releases) и выберите его в **Настройки → Плагины → Установить плагин…**.

## Что плагин просит и зачем

| Разрешение | Зачем |
| --- | --- |
| `exec` | запускать `op` — официальный 1Password CLI, и только его |
| `clipboard` | копировать поля записи |
| `autofill` | вводить логин и пароль в активное приложение по кнопке |
| `openURL` | открывать сайт из записи |

Сети у плагина нет вовсе: он не может ничего никуда отправить. Пароли он получает
от `op` и кладёт в буфер обмена — больше они никуда не попадают.

`exec` — единственное разрешение, которое выводит за пределы песочницы, поэтому оно
самое узкое: приложение запускает только `op`, только по известным путям, без оболочки,
и отклоняет аргументы вроде `--config` или `--session`, которыми можно было бы подменить
источник данных.

## Разработка

Нужен только Python 3.

```sh
tools/fastplugin check     # манифест разобран и осмыслен
tools/fastplugin stamp     # обязательно после каждой правки plugin.js
tools/fastplugin package   # собрать архив и посчитать sha256
tools/fastplugin release   # тег, релиз и запись для каталога
```

`stamp` обязателен: приложение сверяет sha256 скрипта с тем, что записано в манифесте,
и отказывается запускать плагин, если они разошлись. Так плагин, отредактированный
после установки, не сможет воспользоваться разрешениями, которые вы дали раньше.

Как устроены плагины вообще — [руководство автора](https://github.com/kasaley/fastActionPlugins/blob/main/docs/PLUGINS.md).
Каталог, куда попадают записи о релизах, — [fastActionPlugins](https://github.com/kasaley/fastActionPlugins).
